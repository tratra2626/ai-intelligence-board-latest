01 模型侧

OpenAI 发布三款实时语音模型，把推理、翻译、转写拆成独立 API 能力

OpenAI 在 5 月 7 日推出 GPT-Realtime-2、GPT-Realtime-Translate 和 GPT-Realtime-Whisper。这不是单纯升级语音接口，而是把实时语音推理、同声传译、低延迟转写分别产品化，开发者可以按客服、会议、导览、跨语言沟通等场景拆分调用。

GPT-Realtime-2 主打 GPT-5 级语音推理、工具调用、打断恢复和 128K 上下文；Translate 支持 70+ 输入语言到 13 种输出语言；Whisper 面向流式字幕和实时转写。关键影响是语音 Agent 的竞争会从“能说话”转向“能边说边做事，并且能按分钟或 token 算清成本”。

04 商业化

OpenAI 实时语音模型直接公布单价，语音能力开始形成独立收入曲线

OpenAI 对三类语音模型采用不同定价：GPT-Realtime-2 按音频 token 收费，Translate 和 Whisper 按分钟收费。这意味着 OpenAI 不再把语音当作文本模型的附属能力，而是把实时推理、翻译、转写拆成可单独计费的产品线。

这对开发者很重要：会议转写、客服翻译、电话 Agent、现场导览等场景可以按分钟估算成本；而高推理语音 Agent 则保留 token 计费弹性。语音产品后续会更快进入“单位分钟毛利”和“任务完成率”的竞争。

ChatGPT 新增 Memory Sources，让用户看到回答用了哪些记忆和资料
